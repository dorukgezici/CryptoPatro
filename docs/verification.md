# Rebuild verification

Verified locally on 11 October 2026.

## Automated checks

- Backend: 34 tests passed, plus Ruff lint and formatting checks.
- Frontend: 10 Playwright browser tests passed, plus formatting, native TypeScript checking, Astro checking, and the production build.
- Dependency audit: npm reported zero known vulnerabilities at verification time.

The browser suite covers holding creation, editing, deletion, reload persistence, portfolio isolation, alerts, local copilot answers, public postcard privacy and revocation, image export, keyboard focus restoration, hidden balances, responsive layouts, and missing pages. The backend suite additionally covers financial calculations, unknown cost basis, malformed market responses, non-finite input, sample-price alert suppression, concurrent alert limits, rate limits, Pydantic AI structured output with its test model, provider fallback, share ownership, growth-event validation, exactly-once activation, and database migration rollback.

## Production containers

Both images built and ran successfully on **Linux arm64** in an isolated Compose project. Both service healthchecks passed. Verification exercised:

1. Private holding operations through the frontend's same-origin API proxy.
2. Public share server rendering, runtime canonical origin, and `noindex` metadata.
3. A real 1200 by 630 PNG generated by Sharp, with legible fonts and no private financial fields.
4. Holding and share-history persistence after a backend restart.
5. Owner revocation returning a public 404.
6. The read-only growth report inside the running backend container.

The temporary test containers and their disposable volume were removed after verification. This is local Linux arm64 evidence, not a test of a remote Linux amd64 deployment.

## Remaining launch configuration

No public deployment or domain has been provisioned. Production needs an HTTPS origin, a persistent backend volume, and backups. Optional provider-backed AI needs `CRYPTOPATRO_AI_MODEL` and `OPENAI_API_KEY`; no paid model request was used in this verification. Without those values, the tested local summary mode remains available. Price alerts are evaluated in the app, not delivered in the background.
